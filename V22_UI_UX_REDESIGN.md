# V22 UI / UX Redesign

This pass changes the application shell without removing the simulation systems.

## Direction
- Replaced the crowded horizontal module ribbon with a persistent left navigation rail.
- Added collapsible navigation and remembered its state in local storage.
- Rebuilt the top bar as a compact context header: current module, search, clearance, audio, print, operative and lock.
- Removed the permanent red classification strip from the main workspace and folded classification into the quieter security header.
- Increased content breathing room and reduced competing amber/red accents.
- Kept existing mission, archive, persona, debrief, radio, save and admin logic intact.

## Menu structure
1. Command Centre
2. Mission Simulator
3. Dossier Archive
4. Intel Network
5. Bond Movies
6. Bond Persona
7. Archive Admin

Mission Simulator is intentionally placed directly below Command Centre because it is the core gameplay loop.

## Theme
"Quiet Intelligence": dark graphite/navy surfaces, restrained warm brass accents, soft green live-state indicators, thin borders and less decorative telemetry noise.
