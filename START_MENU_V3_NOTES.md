# MI6 Start Menu V3

Rebuilt the launch experience around a cinematic secure-entry screen rather than an admin portal.

## Changes
- Removed the large light login card.
- Added a dark/warm full-screen MI6 operations identity and status hero.
- Converted all six entry destinations into functional selectable routes.
- Login remains prefilled and requires only one click.
- The login action now enters the selected destination directly.
- Added live clearance feedback when the selected operative cannot access a destination.
- Added compact operative selector for 007, M and Q.
- Added routing preview, archive statistics and more restrained operational telemetry.
- Preserved the existing authentication/session system and all simulator/dashboard upgrades.
