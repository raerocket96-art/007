# Mission Menu / Settings Rework

This build reorganizes the live Mission Simulator around a cleaner gameplay-first view.

## New Mission Menu
- Navigation to Command Centre, Dossier Archive, Intel Network, Global Telemetry and Archive Admin.
- Mission autosave remains active when leaving the simulator.
- Quick Save, Save Vault, Causal Tree and Film Comparison moved into the menu.
- Finish & Debrief, open Final Debrief and return to pre-deployment are available from one place.

## New simulator settings
- Focused HUD / Full HUD presets.
- Toggle mission stage rail.
- Toggle situation-shift analysis.
- Toggle recent activity log.
- Toggle expanded intel panel.
- Toggle Bond doctrine statistics.
- Toggle AI/fallback engine badges.
- Toggle generated suggested actions.
- Toggle AI scene illustrations.
- Settings persist in localStorage.

## Cleaner live mission screen
- Removed operation/actor selectors from the active mission header.
- Live header now shows only active 007, turn/stage and Mission Menu.
- Advanced utilities no longer crowd the main gameplay toolbar.
- Focused HUD is the new clean default.

## Scene illustration integration
- Scene image on/off is now controlled from Mission Settings.
- Per-scene regenerate/retry UI remains available internally, while the live mission surface stays cleaner.
