# MI6 Mission Simulator Dashboard V2

## Reworked cockpit hierarchy
- Central gameplay surface is now the visual priority.
- Current Situation + Immediate Objective sit at the top of the game surface.
- Decision Board sits directly under the current scene.
- Custom actions remain available but no longer dominate the layout.

## Right rail simplified
The permanent right side now contains only:
1. Mission Status / live telemetry
2. Live Intelligence Picture
3. Active Bond Doctrine

Field Package, inline Causal Tree, and inline Save Vault were removed from the right rail.

## Secondary toolbar
- Causal Tree
- Save Vault
- Compare Film
- Quick Save
- Abort

These are still fully accessible but no longer compete with the current scene.

## Visual changes
- Warmer dark brown/charcoal MI6 operations-room palette.
- Reduced bright paper-like surfaces.
- Decision cards are darker and clearer.
- Mission stages are a thin rail rather than a dominant block.
- Operational history is secondary and placed below the main gameplay surface.
